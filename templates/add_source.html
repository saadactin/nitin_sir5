About Data Sources

  • • SQL Server: Connect to any Microsoft SQL Server instance (including named instances)
  • • SAP HANA: Connect to SAP HANA in-memory database for enterprise data integration
  • • API Endpoint: Fetch data from REST APIs with support for various authentication methods
  • • Target Systems: Sync data to PostgreSQL for relational storage or ClickHouse for analytics
  • • Automated Sync: Schedule automated synchronization or trigger manual syncs as needed
