How it works:

  • Each file will be created as a separate table in PostgreSQL
  • Table name will be based on the filename (special characters removed)
  • If a table with the same name exists, it will be replaced
  • CSV files: First row must contain column headers
  • Excel files: Only the first sheet will be imported
  • Text files: Auto-detects tab, comma, or space delimiters
