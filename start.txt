Project Setup and Run Guide
Prerequisites
System Requirements
Windows Machine with PowerShell

Python 3.11+ installed and on PATH

Microsoft ODBC Driver 18 for SQL Server (if connecting to SQL Server sources)

PostgreSQL Server (local or remote)

Install ODBC Driver for SQL Server
Download and install from Microsoft:
https://docs.microsoft.com/en-us/sql/connect/odbc/download-odbc-driver-for-sql-server

Quick Setup Script
Save the following as setup.ps1 and run in PowerShell:

powershell
# setup.ps1 - Automated project setup

# Create virtual environment
python -m venv .venv

# Set execution policy for current process
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force

# Activate virtual environment
. .\.venv\Scripts\Activate.ps1

# Upgrade pip and install dependencies
python -m pip install --upgrade pip
pip install -r .\requirements.txt

Write-Host "Virtual environment setup complete!" -ForegroundColor Green
Write-Host "Don't forget to configure db_connections.yaml" -ForegroundColor Yellow
Manual Setup Steps
1. Create and Activate Virtual Environment
powershell
# Create virtual environment
python -m venv .venv

# Bypass execution policy if needed
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force

# Activate virtual environment
. .\.venv\Scripts\Activate.ps1

# Verify Python path
python --version
2. Install Python Dependencies
powershell
# Upgrade pip
python -m pip install --upgrade pip

# Install requirements
pip install -r .\requirements.txt

# Optional: Install pytest for testing
pip install pytest
3. Configure Database Connections
Edit db_connections.yaml with your PostgreSQL details:

yaml
postgresql:
  database: sync_db
  host: localhost
  password: YourPgPass
  port: 5432
  schema: CompanyDB
  username: migration_user
sqlservers: {}
4. Setup PostgreSQL Database
Option A: Using Existing PostgreSQL Server
powershell
# Set variables - adjust these values
$PGADMIN = "postgres"
$PGHOST = "localhost"
$PGPORT = 5432
$PGDB = "postgres"
$NEWDB = "sync_db"
$NEWUSER = "migration_user"
$NEWPASS = "StrongPassword123"

# Create user
psql -U $PGADMIN -h $PGHOST -p $PGPORT -d $PGDB -c "CREATE USER $NEWUSER WITH PASSWORD '$NEWPASS';"

# Create database
psql -U $PGADMIN -h $PGHOST -p $PGPORT -d $PGDB -c "CREATE DATABASE $NEWDB OWNER $NEWUSER;"

# Grant privileges
psql -U $PGADMIN -h $PGHOST -p $PGPORT -d $PGDB -c "GRANT ALL PRIVILEGES ON DATABASE $NEWDB TO $NEWUSER;"
Option B: Using Docker (Quick Start)
powershell
# Start PostgreSQL container
docker run -d --name local-postgres -e POSTGRES_PASSWORD=StrongPassword123 -e POSTGRES_USER=postgres -e POSTGRES_DB=postgres -p 5432:5432 postgres:15
Then create the database and user as shown in Option A.

5. Initialize Database Schema
powershell
# Initialize PostgreSQL schema
python -c "from db_utils import init_pg_schema; init_pg_schema(); print('Schema initialized successfully')"

# Create default admin user (admin/admin123)
python -c "from auth import init_admin_user; init_admin_user(); print('Admin user initialized')"
6. Add SQL Server Connections (Optional)
powershell
# Add SQL Server connection
python manage_server.py --add myserver "sqlhost\INSTANCE" sa "password123"

# List all configured servers
python manage_server.py --list

Ensure PostgreSQL is running and accessible

pyodbc Installation Failures

Confirm Microsoft ODBC Driver is installed

Check driver version compatibility
